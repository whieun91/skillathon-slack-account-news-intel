# Slack Summary Template

Use this format for a message the user can paste into Slack. Keep it concise and readable in a channel.

```markdown
*[주간 고객사 뉴스 인텔리전스] YYYY-MM-DD*

*긴급 리스크*
- *Demo Enterprise Group* | 협업툴 전환 관련 공개 보도 | 리스크: 매우 높음
  - 액션: 사용 현황, 계약/갱신일, 대체 툴 도입 범위 즉시 확인

*Upsell / Ent+ 기회*
- *Demo Travel Platform* | 서비스 영역 확장 및 성장 신호 | 기회: 높음
  - 액션: 부서 간 협업, 파트너 워크플로우, 보안/관리 요구 기반 Ent+ 대화 제안
- *Demo Petcare* | Pre-IPO 및 투자 유치 신호 | 기회: 중간-높음
  - 액션: 현재 Slack 사용 여부와 조직 확장 계획 확인

*New Logo / DX 신호*
- *Demo Industrial Group* | Google Workspace 도입 및 AX/DX 추진 | 기회: 중간
  - 액션: 전사 협업 허브와 업무 자동화 관점으로 Slack fit 검증

*이번 주 AE 체크리스트*
1. 긴급 리스크 계정 owner 확인
2. high-confidence 기회 계정에 미팅 명분 생성
3. plan unknown 계정의 Slack 사용 여부 업데이트
```

## Rules

- Use bold account names and compact labels.
- Include only the top accounts, usually 5-10.
- Avoid long source lists in Slack. Put detailed sources in the Markdown report.
- Mention severe attrition risks before opportunities.
- If confidence is low, say "확인 필요" instead of making a firm recommendation.
